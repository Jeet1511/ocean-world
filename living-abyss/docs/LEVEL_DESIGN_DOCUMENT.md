# Level design and route evidence

The seven regional intentions and entry descriptions are defined by LOCATIONS in `geography.js`; the full spatial geography remains as selected. Local approach probes cover four directions around each of the seven existing gates, not paths between destinations. The in-game map supports a player-selected marker and moving distance/bearing, but the straight line is **not** collision-aware.

Open: inspect and document actual entry, reveal, optional paths, vertical clearance and exit for each location using live swimming and screenshots. Do not promote gate-local tests to full-world route verification.
