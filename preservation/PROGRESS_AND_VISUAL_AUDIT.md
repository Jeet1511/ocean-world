## Follow-up — kelp blade geometry repair

Changed `living-abyss/src/world/flora.js` only. Investigation found that each blade's width axis was almost parallel to its outward length, collapsing broad ribbons into very thin overlapping triangles and producing unstable normals. The blades now use a transverse width axis with a small deterministic tilt, attach continuously along the existing curved stipe rather than snapping to the nearest segment, and use a narrow-base / broad-middle / tapered-tip profile with a slight arch. The original four species, seeded generation order, instance counts, placements, forest bounds, sway system, controls and world geography were retained. No new draw calls or blade segments were introduced; actual GPU performance has not been measured.

The matched before image is `visual-audit/after-verdant-cathedral.png` (the state before this follow-up); `visual-audit/kelp-refined-matched.png` uses the same camera pose and low-quality software WebGL. `kelp-refined-low.png` shows an additional viewpoint. The blades are visibly broader and more coherent than the needle-like previous result, but still look geometrically simple and the forest remains far from the reference's quality. The intermediate `kelp-pass-*.png` files are retained to show iteration. This is an incremental repair, not a finished destination.

After the repair: application reached ready in Chromium/SwiftShader with no observed page or non-favicon console errors; flora reports 2,820 kelp, 6,600 seagrass and 15,019 coral instances. Source syntax checks and the world and sampled geology mesh validators pass. This is not a full exploration, collision, animation, visual, or hardware-performance certification. The 2026-10-30 pre-enhancement snapshot remains the rollback source for `flora.js`.

## Follow-up — portal, collision and kelp material pass

Backup immediately before this pass: `pre-portal-collision-pass.zip`. All edits are reversible against that snapshot.

### Changes
- Portal dial now releases pointer lock so the mouse can select destinations, stops swim input while open, supports Escape, and scrolls within short viewports. The proximity prompt explicitly says to press E. Arrival is placed on the destination side of the existing gate rather than farther from its destination centre. Gate locations and existing travel mechanics are unchanged.
- Terrain slide re-samples the floor at the actual slid position rather than using the height of a rejected position. World boundary now allows movement to within the body radius of the authored edge instead of stopping 60 m inward; a boundary remains at the actual map edge.
- Cavern upward collision now tests the actual roof shell rather than large flat circular ceiling bands. Existing gates in the shell remain openings. Boulder collisions use conservative ellipsoids derived from each actual boulder's bounds instead of broad full-height cylinders. Procedural wall collision centres follow the same curved wall path rather than a straight line displaced from the visible wall. These changes are approximations, not proof that every collision and cave entrance is correct; conservative colliders can allow some visible-edge overlap.
- Kelp blades now carry local coordinates and a procedural tissue, midrib, and edge pigment treatment that moves with the plants. This is a modest material improvement, not imported high-resolution PBR assets or a finished vegetation overhaul. `visual-audit/kelp-texture-pass.png` is an actual low-quality software-WebGL capture. The forest still looks simplified relative to the user's references.

### Tests and limitations
- Chromium/SwiftShader test at 480×270: acquired pointer lock, opened a gate, verified pointer lock released and Escape closed the dial; then clicked a destination from each of the seven gates and verified each arrival was within 55 m of the target gate (measured 30 m in all seven cases). The small viewport exercise discovered and verified the scroll fix. No page or non-favicon console errors were observed. The test used diagnostic positioning to reach each source gate; it did not swim the full world routes.
- `tests/gate-approach-audit.mjs`: deterministic controller simulation starting 30 m from each gate along four cardinal directions reached all seven gate proximity volumes (28/28 approaches). This does not establish full-world route clearance, test all swimming depths, or account for every visible surface.
- `tests/navigation-regression.mjs`: tests rejected-slope resampling, ascent into a sample visible roof versus ascent in open water, and the corrected world-edge margin.
- World and sampled geology mesh validators passed after the main changes. No GPU benchmark on the RTX 3050 has been performed. Actual cave shells, arches, remaining hero colliders, and all real exploration routes still require extensive live inspection; do not claim all invisible walls are gone. The kelp material pass is far short of the requested high-quality ecosystem and texture upgrade.
